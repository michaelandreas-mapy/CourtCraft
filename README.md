# 🏀 CourtCraft: Basketball Attribute Engine

CourtCraft adalah sebuah aplikasi web interaktif yang mensimulasikan sistem pembuatan pemain basket (*player builder*) layaknya video game. Pengguna dapat mendistribusikan poin atribut, melakukan *gacha roll* untuk mendapatkan potensi maksimal, dan melihat hasil akhirnya dalam bentuk kartu koleksi digital yang dinamis.

Proyek ini saya buat untuk mencoba praktek. Tema dan ide ini sendiri muncul karna saya suka bermain video game NBA 2K, maka dari situ saya terinspirasi membuat prototype builder my player sederhana dari 0. 

## ✨ Fitur Utama

*   **Dynamic OVR Calculation:** Sistem kalkulasi *Overall Rating* (OVR) yang dinamis berdasarkan distribusi 5 atribut utama (Finishing, Speed, Shooting, Playmaking, Defense).
*   **Gem Tier Grading System:** Kartu akan berevolusi secara visual (Bronze, Gold, Sapphire, Ruby, Amethyst, Diamond) yang bereaksi terhadap pencapaian OVR pengguna.
*   **"Shades Of" Player Matching:** Algoritma yang mencocokkan gaya bermain pengguna dengan bintang NBA asli (atau pemain *generic* jika belum maksimal).
*   **Scouting Report:** Menampilkan deskripsi gaya bermain secara *real-time* berdasarkan hasil *build* pengguna.

## 🛠️ Teknologi yang Digunakan

*   **HTML5** 
*   **CSS3** 
*   **Vanilla JavaScript**
